# Русский язык: миссия невыполнима?

Вертикальный анимационный ролик для конкурса ИИ-видео «НейроНаука» (Десятилетие науки и технологий в России).

**Готовый фильм:** [`release/russkiy-yazyk-missiya-nevypolnima.mp4`](release/russkiy-yazyk-missiya-nevypolnima.mp4)

| Параметр | Значение |
| --- | --- |
| Длительность | 90 секунд (2700 кадров) |
| Формат | вертикальный 9:16, 1080 x 1920, 30 кадров/с |
| Видео | H.264 High, yuv420p, BT.709 |
| Звук | AAC, 48 кГц, стерео: русская озвучка, музыка, звуковые эффекты |
| Субтитры | русские, вшиты в изображение, совпадают с озвучкой дословно |

## Сюжет

1. **0:00-0:12.** Зимний Санкт-Петербург, герой выходит из аэропорта. Уведомление «ДОБРО ПОЖАЛОВАТЬ В РОССИЮ!» и «СЛОЖНОСТЬ: ЭКСТРЕМАЛЬНАЯ». Мир превращается в игру, на героя летят «Ы», «Ъ», «Щ» и слово «ДОСТОПРИМЕЧАТЕЛЬНОСТЬ».
2. **0:12-0:27.** Время замирает, появляется робот. Диалог про падежи, титр «РУССКИЙ ЯЗЫК. УРОВЕНЬ 1».
3. **0:27-0:45.** Арена, шесть боссов-падежей. Босс «Родительный падеж», подсказка «НЕТ КОГО? СТУДЕНТА!», победа, «УРОВЕНЬ ПРОЙДЕН! +100 XP».
4. **0:45-1:05.** Университет и лаборатория, закадровый текст о российских разработках, карточка с реальным примером, шутка про меню в столовой.
5. **1:05-1:20.** «НЕСКОЛЬКО ЛЕТ СПУСТЯ...»: герой в костюме выступает на конференции, зал аплодирует.
6. **1:20-1:30.** Вопрос про «надеть» и «одеть», растерянный взгляд, звук ошибки, финальные титры.

## Как пересобрать

Нужны Node.js 20+, Python 3 (numpy, scipy, opencv, librosa, soundfile, pyloudnorm, Pillow) и ffmpeg.

```bash
npm ci
```

```bash
npm run render
```

```bash
bash scripts/export.sh
```

Первая команда ставит зависимости, вторая рендерит мастер `out/master.mp4` (Remotion, около 10 минут на 4 ядрах), третья делает финальный файл в `release/` и печатает его параметры.

Шаги подготовки материалов уже выполнены, их результат лежит в `public/` и `src/*.json`. Повторять их нужно только при замене исходников:

```bash
python3 scripts/prep_assets.py source-assets
```

```bash
python3 scripts/enhance_assets.py source-assets path/to/EDSR_x4.pb
```

```bash
python3 scripts/voice_env.py source-assets
```

- `prep_assets.py` вырезает персонажей из листов, готовит кадры и клипы, досинтезирует музыку и сводит звук (`public/audio/mix.wav`, ровно 90 с).
- `enhance_assets.py` чистит контуры, заново вырезает боссов и повышает чёткость персонажей в 4 раза. Модель EDSR x4 (открытая, Apache 2.0) берётся из репозитория `Saafke/EDSR_Tensorflow`; для неё нужен OpenCV 4.x. Без файла модели скрипт использует обычное масштабирование.
- `voice_env.py` считает огибающие голосов: по ним мигает динамик робота и двигаются персонажи.

Быстрый просмотр отдельных кадров:

```bash
node scripts/stills.mjs out/stills 10.6,33.9,60.9 0.5
```

## Что сделано нейросетями, а что собрано локально

Нейросети (платформа ElevenLabs):

- изображения: Nano Banana Pro и Nano Banana 2 (листы персонажей и 10 ключевых кадров);
- видео: OmniHuman 1.5 (клип с синхронизацией губ, реплика «Я просто хотел учиться!») и Veo 3.1 Lite (реакция героя);
- голоса: три синтетических голоса, созданных в Voice Design, озвучка моделью Eleven v4. Голоса реальных людей не имитируются;
- музыка и звуковые эффекты: ElevenLabs Music и Sound Effects;
- проверка текста озвучки: распознавание Scribe.

Локально:

- монтаж, движение камеры по кадрам, вырезанные персонажи, титры, инфографика, субтитры: Remotion;
- повышение чёткости персонажей: EDSR x4;
- часть музыки (чиптюн на арене, финальная тема, финальный аккорд) синтезирована скриптом;
- сведение звука и экспорт: Python и ffmpeg.

Текст для анкеты конкурса (поле «использованные ИИ-инструменты», до 500 знаков):

> ElevenLabs: изображения Nano Banana Pro и Nano Banana 2 (персонажи, ключевые кадры), видео OmniHuman 1.5 и Veo 3.1 Lite, синтетические голоса Voice Design и озвучка Eleven v4, музыка и звуковые эффекты ElevenLabs. Проверка озвучки: Scribe. Повышение чёткости: EDSR. Монтаж, титры и субтитры: Remotion, ffmpeg.

## Научная достоверность

В ролике показан один реальный пример российской разработки:

> GigaAM: открытые модели распознавания русской речи. SaluteDevices, Interspeech 2025.

Источники: статья arXiv:2506.01192, архив ISCA (`kutsakov25_interspeech`), открытый код `github.com/salute-developers/GigaAM` (лицензия MIT). Числа и сравнения в ролике не приводятся.

Остальное в сюжете вымышлено и так и обозначено:

- схема «речь, распознавание, текст» подписана как «Схематичная иллюстрация»;
- проект героя на слайде подписан «КОНЦЕПТ ИССЛЕДОВАНИЯ»;
- в финале стоит строка «Все персонажи и проект героя вымышлены. Ролик создан с помощью нейросетей.»

Грамматика в кадре проверена: названия и вопросы шести падежей, «Нет кого? Студента!», в слове «достопримечательность» 21 буква.

## Логотип Десятилетия

Официальный логотип в файл не встроен: сайты с пакетом логотипов были недоступны из среды сборки. В финале стоит текстовое упоминание «ДЕСЯТИЛЕТИЕ НАУКИ И ТЕХНОЛОГИЙ В РОССИИ». По правилам конкурса допускается логотип или упоминание.

Чтобы добавить логотип:

1. скачайте пакет с официальной страницы конкурса (`neuronauka.scienceid.net`, раздел с логотипами);
2. положите PNG как `public/logo/dnt-logo.png`;
3. в `src/assets.json` поставьте `"hasLogo": true`;
4. выполните `npm run render` и `bash scripts/export.sh`.

Логотип появится на белой плашке под финальными титрами. По брендбуку его нельзя перекрашивать, искажать и ставить на пёстрый фон.

## Честные компромиссы

- Это не сплошное ИИ-видео. Живых ИИ-клипов два (около 3,5 секунды экранного времени, клип с речью использован дважды). Остальное: ИИ-кадры с движением камеры, вырезанные ИИ-персонажи и графика.
- Синхронизация губ есть только в кадрах с клипом. В реплике «Даже падежи?» использован тот же клип, губы там двигаются в ритм, но не по звукам.
- Костюм героя в сценах 5-6 получен перекраской куртки и рисованным галстуком, отдельной генерации не было.
- Кредиты ElevenLabs закончились на середине производства, поэтому часть сцен собрана графикой вместо сгенерированных кадров.
