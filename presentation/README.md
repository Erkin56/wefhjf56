## Пересборка

Нужны 14 фото из папки на Google Диске, сохранённые как `p01.jpg` ... `p14.jpg` (в порядке загрузки, от новых к старым), Python 3 с Pillow, numpy, fontTools и Node.js с `pptxgenjs@3.12.0`.

```bash
python3 source/make_assets.py photos/ assets/        # кадрирование фото, ткань-икат, медальон
node source/build_deck.js assets/ deck.pptx <pptx-skill-dir>
python3 source/dedupe_media.py deck.pptx             # одна копия каждой картинки
soffice --headless --convert-to pdf deck.pptx
```
